# 📰 React News Application Dashboard

A dynamic, real-time news application dashboard built with **React.js** and styled with **Bootstrap**, featuring live data integration from the **News API**. Inspired by the **CodeWithHarry React Course**, this project showcases modern frontend development practices, single-page application (SPA) routing, and seamless asynchronous data fetching.

## 🚀 Key Features

* **Live Data Integration:** Fetches real-time, global breaking news headlines using the News API.
* **Category Navigation:** Smooth client-side routing across diverse sections like Business, Technology, Entertainment, Health, Science, and Sports.
* **Infinite Scroll:** Delivers an uninterrupted reading experience by automatically loading more articles as the user scrolls.
* **Visual Anchors & Loaders:** Features a sleek top loading progress bar and custom spinner animations to indicate active data fetching.
* **Fully Responsive Design:** Built with a mobile-first approach using Bootstrap, ensuring a clean layout across desktops, tablets, and smartphones.

## 🛠️ Tech Stack & Concepts Covered

* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3
* **Styling:** Bootstrap 5
* **Routing:** React Router DOM
* **State & Data Management:** Asynchronous Fetch API / Axios, React Hooks (useState, useEffect) or Class Lifecycle Methods
* **External APIs:** News API
